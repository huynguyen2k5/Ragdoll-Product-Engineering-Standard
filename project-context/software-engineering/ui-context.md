# UI Context

## Status

`NOT_APPLICABLE` to a standalone application UI in the current milestone.

Ragdoll is currently a source repository, Skill/standard, local reference utilities, documentation, and IDE integration package.

## Current Presentation Surfaces

- GitHub README/documentation.
- Project Context/reference Markdown.
- CLI JSON output from deterministic helpers.
- Antigravity integration instructions.
- Future installer prompts/output.

## Presentation Intent

Public content should feel precise, technical, calm, inspectable, privacy-conscious, and evidence-driven. Avoid exaggerated autonomous-AI claims.

## Terminology

Use these consistently:

- Engineering Standard
- Context Standard
- Context Domain
- Project Context
- Project History
- Runtime Context
- Active Intelligence
- local-first

Do not imply that Ragdoll is a model provider, mandatory cloud platform, or general-purpose coding harness.

## CLI UX Principles

- Prefer machine-readable JSON plus clear exit codes for deterministic utilities.
- Destructive operations require explicit identifiers/confirmation.
- Do not hide privacy/security defaults.
- Errors should explain what failed without leaking secret values.

## Brand / Visual System

- Product brand: `Ragdoll`.
- Formal project name: `Ragdoll Product Engineering Standard`.
- Application color system: UNDECIDED / NOT_APPLICABLE.
- Typography system: UNDECIDED / NOT_APPLICABLE.
- Component library: NOT_APPLICABLE.
- Icon system: NOT_APPLICABLE.

Do not invent a visual design system until a real interactive surface is scoped.

## Accessibility

Future interactive surfaces must define keyboard/focus, contrast, readable type, and non-color-only state communication before implementation.

## Context Provenance

- **OBSERVED:** Current user-facing surfaces are Markdown documentation, CLI output, repository files, and integration instructions.
- **DECLARED:** No standalone Ragdoll application UI is in current scope.
- **INFERRED:** Installer or future local application UX may later require a dedicated product-design context domain.
- **UNDECIDED:** Visual identity tokens, application design system, component library, and website UI.
